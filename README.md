# ABNIEX

Abre `index.html` en tu navegador.

```text
index.html          Portada, servicios y portafolio
contacto.html       Formulario de contacto por WhatsApp
legal/              Privacidad, cookies y términos
css/                Hojas de estilo
js/                 Menú, portafolio y formulario
assets/
  marca/            Logotipos
  servicios/        Imágenes de servicios
  portafolio/       Captura del panel y mockups de proyectos
```

Para publicar, conserva las rutas de los archivos HTML y de las cuatro carpetas.
